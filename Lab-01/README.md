# Lab 01 - Introduction to Relational Databases

## Overview

This lab introduces the fundamental concepts of relational databases and database management systems (DBMS).

## Topics Covered

- Database and DBMS
- Relational databases
- SQL (Structured Query Language)
- Tables, rows, and columns
- Primary keys and foreign keys
- Schema, queries, indexes, and normalization
- Database relationships:
  - One-to-One
  - One-to-Many
  - Many-to-Many
- SQL vs. NoSQL databases
- ACID properties
- Introduction to PostgreSQL
- Comparison of PostgreSQL with MySQL, SQLite, and Oracle
