# Lab 03 - Basic psql Commands

## Overview

This lab covers basic PostgreSQL operations using the psql command-line interface.

## psql Commands Practiced

- `\l` - List all databases
- `\dt` - List tables in the current database
- `\d students` - Display the structure of the students table
- `\h` - Display help for SQL commands
- `\?` - Display available psql commands
- `\q` - Exit psql

## SQL Commands Practiced

- CREATE TABLE
- INSERT
- SELECT
- DROP TABLE

## Practice Table

A `students` table was created with the following columns:

- `id` - SERIAL PRIMARY KEY
- `name` - VARCHAR(100)
- `age` - INT

Two sample records, Alice and Bob, were inserted and retrieved using a SELECT query.
