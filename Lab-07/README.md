## 1. Objective

The objective of this lab is to understand the concept and importance of primary keys in relational databases.

This lab demonstrates how to create and manage primary keys in PostgreSQL, including single-column primary keys, composite primary keys, automatically generated identifiers, and primary key constraints.

## 2. What Is a Primary Key?

A primary key is a column or combination of columns that uniquely identifies each record in a database table.

Primary keys have the following characteristics:

- Uniqueness: Each primary key value must be unique.
- NOT NULL: Primary key values cannot be NULL.
- One primary key per table: Each table can have only one primary key constraint.
- Stability: Primary key values should generally remain unchanged.

Primary keys help maintain data integrity, establish relationships between tables, and improve query performance.
