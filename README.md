# Database - Fall 2026

This repository contains my coursework, lab assignments, SQL exercises, and practical work for the Database course at the American University of Central Asia (AUCA).

## Course Overview

Throughout this course, I am learning how relational databases work, how to design and manage databases, and how to use PostgreSQL to store, retrieve, modify, and analyze data.

The repository documents my progress, practical exercises, and understanding of database management concepts.

## Course Topics

The main topics covered throughout the course include:

- Relational Database Concepts
- Database Management Systems (DBMS)
- PostgreSQL Installation and Configuration
- SQL Fundamentals
- Tables, Rows, and Columns
- Primary Keys and Foreign Keys
- Database Relationships
- Database Design and Normalization
- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Data Retrieval and Filtering
- SQL Aggregate Functions
- GROUP BY and HAVING
- SQL JOIN Operations
- Subqueries and Common Table Expressions (CTEs)
- Recursive Queries
- Window Functions
- Advanced SQL Querying
- Database Transactions
- ACID Properties
- Transaction Isolation Levels
- Data Import and Export
- Database Backup and Recovery
- Query Optimization and Performance

## Technologies and Tools

The main technologies and tools used in this course are:

- **PostgreSQL:** Relational database management system.
- **SQL:** Language used to create, manage, and query databases.
- **psql:** PostgreSQL command-line interface.
- **pgAdmin:** Graphical interface for PostgreSQL database management.
- **GitHub:** Version control and documentation of coursework.
