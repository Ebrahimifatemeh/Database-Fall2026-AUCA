# Database - Fall 2026

This repository contains my coursework, lab assignments, SQL exercises, and practice for the Database course at AUCA.

## Course Topics

Throughout this course, I will be working with relational databases and PostgreSQL, including:

- Relational database concepts
- Database Management Systems (DBMS)
- PostgreSQL
- SQL queries
- Tables, rows, and columns
- Primary and foreign keys
- Database relationships
- Data retrieval and filtering
- Database design and management

## Labs

- Lab 01 - Introduction to Relational Databases
- Lab 02 - PostgreSQL Installation
- Lab 03 - Basic psql Commands
- Lab 04 - First SQL Query

More labs and exercises will be added throughout the semester.
